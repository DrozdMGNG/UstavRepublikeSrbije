# Устав Републике Србије — GitHub Pages

Овај фолдер је спреман за објављивање као сајт преко **GitHub Pages**.

## Садржај
- `index.html` — главна (и једина) страница
- `styles.css` — стилови
- `images/` — слике (грб, заставе, мапа)

## Како да објавиш (GitHub Pages)
1. Направи нови repo на GitHub-у (нпр. `ustav-republike-srbije`).
2. Убаци у repo *све* из овог фолдера тако да `index.html` буде у **root**-у repo-а (не у подфолдеру).
3. Push на `main` грану.
4. Иди на **Settings → Pages** у repo-у.
5. Под "Build and deployment" → "Source" избери **Deploy from a branch**, грана `main`, фолдер `/ (root)`. Сачувај.
6. За 1-2 минута сајт ће бити доступан на:
   `https://<твоје-корисничко-име>.github.io/<назив-repo>/`
